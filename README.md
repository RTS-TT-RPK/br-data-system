# 数据系统开发（br-app 预览版）

> 本仓库是工作区「03_数据系统开发」的代码 + 文档导出（L3 Django 数据应用）。
> 业务原始资料（旧 BR 数据库 `.xlsm`、VBA/旧表迁移快照、预览数据库、界面截图、Gemini 审核材料等）**不随仓库发布**；含真实库存/来料明细的文件（`示例_综合物料汇总.xlsx`、本地真实种子）只留在本地工作区。公开仓库自带的是**全部虚构的合成示例种子** `seeds/legacy_data.json`。排除规则见根目录 `.gitignore`；跨层文档快照见 `docs/`。
> 上游 L1 识别 + L2 审核台在「图像识别」仓库，本仓库通过 `reviewed.json` 契约接收审核结果。

当前开发入口：03_原型与代码/br-app（L3 Django 数据应用）。

## 首次运行说明（重要）

本仓库自带**合成演示种子**（`03_原型与代码/br-app/seeds/legacy_data.json`，全部为虚构示例，不含真实业务数据），可直接运行：

- `启动预览.bat` 会执行 `migrate` 并灌入合成示例种子；
- 也可以手动：`python manage.py migrate` → `python manage.py seed_preview`；
- 含真实数据的文件（`示例_综合物料汇总.xlsx`、本地真实种子、界面截图等）不随公开仓库发布，只留在本地工作区。

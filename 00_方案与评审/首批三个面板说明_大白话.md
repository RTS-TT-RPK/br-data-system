# 首批三个面板：大白话说明

> 用途：在动手前，用你现有的 Excel 表和数据，把“这三个面板到底是什么、你会怎么用”讲清楚。
> 不是技术文档；技术细节见《架构设计说明_v2.0》和《数据结构_宽表长表与成分明细》。

---

## 0. 先说“面板”是什么

把 Excel 里的一个工作表，原样搬到网页上：

- 列名一样、一行一行一样；
- 能滚动、筛选、排序、搜索；
- 能点“新增”加一行、点一行改、删除；
- 数据可以是人填的，也可以是 Agent/插件从图片里读出来送进来的。

**一个面板 = 一张会动的 Excel 表。**

所谓“通用面板”，就是：这种网页只写一次，以后每张表通过“配置”（列名、宽度、必填、样式）生成，不用为每张表单独写页面。

---

## 1. 物料性质（主数据）

### 大白话

**“我们厂有哪些物料、每种物料是什么东西”的档案柜。**

一行 = 一种物料（示例溶剂A、示例溶剂B、示例溶剂C……），不能重复。

### 表里有什么

示例种子里有 3 种物料，列就是你 Excel 里的：

| 列 | 大白话 |
|---|---|
| 中文名 | 平时叫它什么 |
| 英文名/缩写 | 英文或简称 |
| CAS号 | 化学品的“身份证号” |
| 沸点、密度、闪点 | 基本物性 |
| 挥发速率、饱和蒸气压、光敏性 | 安全/工艺参考 |
| IARC、GHS、OEL | 危害分类和职业接触限值 |
| 市场参考价 | 参考用，不是结算价 |
| 备注 | 其他说明 |

### 你会怎么用

- 新物料来了：在这里加一行；
- 名字写错/别名：在这里改；
- 别的面板选物料时，从这里选，避免“示例溶剂A/示例溶剂A（工业）/DemoSol-A”各写各的；
- 密度、CAS 这些，别的面板可以引用，少填一遍。

### 为什么先做它

**它是字典。** 字典乱了，库存、来料、投料全跟着乱。先把示例物料导进来，后面所有面板的“物料”列都能选它。

### 它不是什么

- 不是库存：这里不记“有多少”；
- 不是来料记录：这里不记“哪一批”；
- 它只回答“这种物料是什么”。

---

## 2. 物料库存（含成分）

### 大白话

**“现在每个库位/罐里，放的是什么、有多少、成分怎么样”的当前快照。**

一行 = 一个储位上的一个物料（或一个批次）的当前状态。

合成示例种子里有 8 行这种记录，其中 2 行带成分明细。

### 表里有什么

| 列 | 大白话 | 例子 |
|---|---|---|
| 储位 | 放在哪个库位/罐 | 示例库区1# |
| 储存区域 | 哪个区域 | 示例库区1# |
| 日期编号 | 这批的日期/编号 | 2026-10-01 |
| 来源 | 产品/原料/退货… | 发货 |
| 名称 | 物料名 | 示例混料1 |
| 性质 | 正常/待检/… | 正常 |
| 成分明细 | 这罐东西的成分，**一格文字** | 示例溶剂B60%、示例溶剂C30%、杂、水1%、PH7 |
| 数量/液位 | 有多少（件/桶/液位） | 1 |
| 体积 | 多少方 | （可空） |
| 重量 | 多少吨 | （可空） |
| 总价 | 金额 | （可空） |

### “含成分”是什么意思

你在表格里看到的还是**一整格原文**（跟 Excel 一样，方便核对）。

但系统在背后会把它拆成一行一行：

| 成分 | 数值 | 单位 | 原文 |
|---|---|---|---|
| 示例溶剂B | 60 | % | 示例溶剂B60% |
| 示例溶剂C | 30 | % | 示例溶剂C30% |
| 杂 | （空） | — | 杂 |
| 水 | 1 | % | 水1% |
| PH | 7 | — | PH7 |

这样你就能问：

- 哪个物料含水最高？
- 哪些库存里含 示例溶剂C？
- 某个成分超过 5% 的有哪些？
- 这罐成分合计是不是 100%？

**表格给人看，拆开的行给电脑查。**

### 你会怎么用

- 每天/每班更新库存：改数量、液位、成分；
- 新进一罐：新增一行；
- 出空了：数量改 0 或作废；
- 看成分：点开成分明细，能看拆分后的每一行；
- 导出：宽表给 Excel，长表给分析。

### 它不是什么

- 不是“出入库流水”：这里只记“现在有什么”，不记“每一笔进出”；
- 第一期不做自动扣账/加账；等以后需要，再加“操作日志/出入库”面板。

## 3. 来料分析（插件表型）

### 大白话

**“每一车/每一桶/每一批原料进厂时，化验室测出来的体检单。”**

一行 = 一个样品（一桶/一批/一车）的来料化验结果。

它跟“物料库存”最容易混，区别一句话：

> **来料分析 = 这批货进厂时的体检记录（历史，一批一行）；**
> **物料库存 = 现在罐里还剩多少（当前状态，一罐一行）。**

### 表里有什么

| 列 | 大白话 | 例子 |
|---|---|---|
| 日期 | 什么时候进的/测的 | 2026-10-27 |
| 位置 | 卸到哪个库/罐 | 示例库区1# |
| 物料 | 送来的什么东西 | 示例溶剂A |
| 批次 | 供应商的批次号 | DEMO-001 |
| 桶号 | 桶/车号 | D01 |
| 厂商 | 谁送来的 | 示例供应商 |
| 成分明细 | 化验结果，一格文字 | 示例溶剂A90% 水5% PH7 |

### 数据从哪来

**主要从图片来：**

1. 你/化验员拍一张来料分析单；
2. DSH 的图像识别插件把表读成结构化数据；
3. 通过 Agent 工具/接口送到这个应用；
4. 应用按“来料分析”面板的列校验、拆成分；
5. 生成**草稿**，你在审核页左边看原图、右边看宽表；
6. 你确认后，才进正式数据。

你也可以手动新增/修改/删除，跟 Excel 一样。

### 为什么先做它

它是“Agent 从图片送数据进来”的第一个真实场景：

- 能验证插件输出能不能接；
- 能验证成分拆分/原文对账；
- 能验证审核页好不好用；
- 能验证重复图片/重复单据会不会重复入库。

### 它不是什么

- 不是库存：来料分析确认后，**第一期不会自动加库存**（避免重复记账）；以后需要再加“按来料更新库存”的动作；
- 不是采购单：这里只记质量/成分，不记价格/付款。

## 4. 三个面板怎么连起来

~~~text
物料性质（字典：有哪些物料）
      │ 选物料
      ▼
来料分析（事件：这批货进厂时成分如何）───→ 人工审核/确认
      │
      │（第一期不自动改库存；以后可加“更新库存”动作）
      ▼
物料库存（状态：现在每个储位有什么、多少、成分如何）
      │
      ▼
查询/分析：含水最高、某成分超 5%、成分合计异常、导出
~~~

- 三个面板共用“物料名/储位/成分明细”这些概念；
- 成分在背后都是拆开存的，所以能横向查询；
- 数据来源三种都支持：人填、Excel 导入、插件/Agent 送。

## 5. 用合成示例种子怎么模拟

合成示例种子里有：

| 数据 | 行数 | 用途 |
|---|---|---|
| 物料性质 | 3 | **合成示例种子**：导入“物料性质”面板 |
| 共沸数据 | 3 | 合成示例：以后做共沸面板 |
| 储存位置定义 | 4 | 合成示例：储位字典 |
| 储罐类型液位体积 | 12 | 合成示例：液位→体积换算表 |
| 物料库存 | 8（2 行有成分） | **模拟 Agent 读图结果**：当作插件一批批送进来，生成草稿→审核→确认 |
| 五金/操作日志 | 2/2 | 面板先建，示例数据 |
| 投料工艺卡/生产记录 | 1/2 行 | 面板先建，示例数据 |

**模拟方式**：把物料库存的 8 行，按“来料分析”的字段重新组织成插件 JSON（日期/位置/物料/成分/批次/厂商），分成几批送到接入接口；看系统能不能：

1. 正确拆成分；
2. 原文拼得回去；
3. 合计不超 100；
4. 重复批次被拦住；
5. 审核页能改、能确认；
6. 确认后能按成分查询。

> 这批示例库存数据只用于模拟，不作为正式库存种子；合成主数据（物料/储位/共沸/标定）随仓库发布，供演示使用。

## 6. 你会在第一版里看到什么

1. 首页有几个面板卡片：物料性质、物料库存、来料分析。
2. 点“物料性质”：3 行示例物料，能改、能加、能导出。
3. 点“物料库存”：8 行，成分列显示原文；点开能看到拆开的成分行；能按成分筛选。
4. 点“来料分析”：有 2 行合成示例；也可点“模拟接入”或由 Agent 送一批 JSON，出现待审核草稿；审核页左图右表（先用占位图/无图），确认后进正式列表。
5. 点“成分查询”：选“水”，按含量排序，看哪些物料含水最高。

---

## 7. 为什么只先做这三个，不做 9 个

三个面板覆盖三种数据形态：

| 形态 | 代表面板 | 验证什么 |
|---|---|---|
| 字典/主数据 | 物料性质 | 下拉引用、唯一性、导入 |
| 当前状态 | 物料库存 | 宽表 CRUD、成分拆分、查询 |
| 外部事件/插件数据 | 来料分析 | Agent 接入、草稿、审核、去重 |

这三种跑通，剩下 6 张表只是“换列/换数据”的配置，不需要再写新页面。

## 8. 其他 6 张 BR 表分别是干什么的（一句话）

| 面板 | 大白话 |
|---|---|
| 共沸数据 | 哪两种物料混在一起会共沸、好不好分离 |
| 储存位置定义 | 厂里有哪些库位/罐位、属于哪个区域、最大多少方 |
| 储罐类型液位体积 | 液位（米）对应多少体积（方）的换算表 |
| 五金配件库 | 螺丝/阀门/配件还剩多少、什么时候该买 |
| 操作日志 | 谁在什么时候改了什么（历史记录） |
| 车间投料工艺卡记录 | 每批投料用什么配方、什么参数、产品要求 |
| 车间生产记录 | 每班生产了什么、收率多少 |

（共 9 张：物料性质、共沸、储存位置、储罐液位、五金、物料库存、操作日志、投料工艺卡、生产记录。）
